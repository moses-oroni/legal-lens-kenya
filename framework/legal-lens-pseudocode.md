# Legal Lens processing logic

```text
INPUT record_or_question

1. DEFINE purpose and decision boundary
2. MINIMISE data to what the purpose requires
3. RECORD provenance, author or custodian, date, location, and jurisdiction
4. CLASSIFY privacy and sensitivity
5. EXTRACT claims; label each fact, inference, recommendation, or personal meaning
6. GRADE evidence A / B / C / D / Q
7. IF conflict exists:
      preserve both versions
      quarantine the disputed claim
      identify the source that could resolve it
8. APPLY Status / Authority / Duty / Proof / Risk / Action
9. IF ambiguity, material risk, repeating pattern, or consequential decision:
      RUN Desk Review
      ASK a curiosity question when interaction is available
10. FORM recommendation with owner, deadline, and closure proof
11. IF action creates an external side effect:
      PRESENT exact action, target, content or data, and consequence
      REQUIRE current action-specific approval
      IF approval absent: STOP before execution
12. RECORD outcome, lesson, and any new safeguard
13. VERSION the output without deleting the earlier evidence trail
```

## Invariants

- No connected source becomes authoritative merely because it is accessible.
- No historical source establishes current status without corroboration.
- No external action inherits consent from monitoring, convenience, silence, or a different action.
- No research convenience justifies unnecessary personal or sensitive data.
- No mistake is closed until its lesson is captured or consciously rejected.
